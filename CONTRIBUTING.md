# Contributing to Typed

Packages' code is generated from an internal spec. So, please do not open PRs: the code would be overwritten. Instead, consider opening issues or reaching out to us at marcel@tribulunation.com

## Filing a bug

Open an issue against the package it's in, using the issue template: the smallest
reproduction you can manage (the failing call, the response that didn't validate, the type
that didn't match), plus the package name and version.
