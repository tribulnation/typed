# Overview

Task-focused guides for Typed Coinbase's real surface — the Coinbase App tier (`app.accounts` v2, `app.advanced_trade` v3 REST plus both WebSocket connections) and Coinbase Exchange (`exchange.http`, `exchange.streams` — the institutional API formerly known as Pro/GDAX).

## Guides

- [Fetch Market Data](fetch-market-data.md) — products, order books, candles, trades. Public, no credentials needed.
- [Manage Account Data](manage-account-data.md) — Coinbase App wallet balances and Advanced Trade brokerage balances, and transaction history.
- [Deposits & Withdrawals](deposits-and-withdrawals.md) — fiat deposits/withdrawals, crypto sends, receive addresses.
- [Place & Manage Orders](place-and-manage-orders.md) — create, edit, cancel, and inspect Advanced Trade orders.
- [Listen To Streams](listen-to-streams.md) — real-time ticker, order book, and order updates over WebSocket.
- [Paginate Through Results](paginate-through-results.md) — walk cursor-paginated endpoints automatically.
- [Fetch Exchange Market Data](fetch-exchange-market-data.md) — Coinbase Exchange products, order books, candles, trades. Public, no credentials needed.
