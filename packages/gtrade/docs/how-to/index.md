# Overview

Task-focused guides for the most common client workflows.

## Included Guides

- [Fetch Market Data](fetch-market-data.md) - markets, prices, order books, candles, trades, funding and price snapshots
- [Query Protocol Data](query-protocol-data.md) - trading variables, open trades, protocol stats, leaderboards, contests and referrals
- [Fetch Account Data](fetch-account-data.md) - balances, positions, open orders, order history and fills
- [Place & Manage Orders](place-and-manage-orders.md) - prepare, broadcast, track, update and cancel orders and positions
- [Paginate Through Results](paginate-through-results.md) - walk order history, fills and trader history page by page
- [Listen To Live Streams](listen-to-live-streams.md) - Trading API channels, backend contract events and live prices
